# Offline do-over pack

Six problems, no internet needed. Per problem:

1. Start a timer.
2. Read STATEMENT.md, write your solution in `solution.go`.
3. Run `go test` in the problem folder until it passes.
4. Stop the timer, write your minutes in the table below.

Rules: notes closed, no Google, failed runs count inside the time,
25-minute cap per problem (a DNF is data, record where you got stuck).

05 and 06 are polish rewrites, not from-blank solves: 05 = single pass,
repeated index expression extracted; 06 = iterate the set, no dead code.
