# Contains Duplicate

Given an integer array `nums`, return `true` if any value appears more than
once in the array. Return `false` if every element is distinct.

**Example**

```
Input:  nums = [1, 2, 3, 3]
Output: true

Input:  nums = [1, 2, 3, 4]
Output: false
```

**Constraints**

- Array length up to ~10^5.
- Values fit in an int, positive or negative.

**Target:** O(n) time, O(n) space (a set).
